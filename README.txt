CENTERLANDS SITE v0.6

Это версия прототипа, подготовленная для публикации как обычный сайт.

Файлы:
- index.html
- manifest.json
- service-worker.js

После публикации по HTTPS:
- открывается на iPhone/Android/Mac как обычный сайт;
- можно добавить на главный экран телефона;
- интерфейс работает в мобильном portrait-режиме;
- после первого открытия часть файлов кэшируется для повторного запуска.

Для GitHub Pages достаточно положить эти 3 файла в корень репозитория
и включить Pages для ветки main / root.
